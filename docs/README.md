# The paper

`1Y-Well-Ordering-KP-Simplified.pdf` (and its extracted text `../paper.txt`) is the paper whose main
theorem this repository formalizes: *A Short Proof of 1-Y Well-Ordering in KP with ω₁*, simplified
version, 12 September 2026.

The paper was shared by its author, the actual prover of the result, in a public instant-messaging
group, without any explicit license. It is included here only as the reference for the formalized
statement and proof. **All rights in the paper belong to its original author.** It is not covered
by this repository's MIT License, and nothing in this repository grants any license to it.
